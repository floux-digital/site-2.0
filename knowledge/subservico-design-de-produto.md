# Subserviço: Design de Produto

## O que é

Um produto é composto por duas hipóteses: a de valor e a de crescimento. Ambas são essenciais para o sucesso. A proposta de valor é o resultado esperado pelo cliente — se ela não for satisfatória, não será possível alavancar o crescimento.

O Design de Produto da Floux transforma insights de pesquisa em interfaces e experiências que entregam valor real para os usuários. O trabalho cria um fluxo criativo com a equipe do cliente para gerar as ideias mais simples, porém capazes de entregar a Hipótese de Valor ao cliente antes do que ele mesmo pode esperar.

## Métodos de design

### Ideação
Geração de novas ideias de forma estruturada. A Floux utiliza ferramentas de design voltadas para elaboração de ideias para desconstruir e redefinir padrões até a obtenção de hipóteses inovadoras, alinhadas à oferta de valor e estratégia definida para o produto.

### Testes
Dar vida a um produto requer investimento de tempo, pessoas e dinheiro. Testar significa antecipar possíveis erros e corrigir a rota antes do prejuízo. A Floux aplica diversos tipos de testes para validar ideias usando protótipos de baixa ou alta fidelidade, de acordo com o momento e necessidade do projeto.

### Design System
Conjunto de regras e componentes modulares para construção de interfaces. Um Design System bem elaborado e documentado gera consistência no desenvolvimento de interfaces, reduz o esforço cognitivo dos usuários e aumenta a performance do time de desenvolvimento.

### Design de Interface
A interface de um produto digital pode ser o principal ponto de contato entre o negócio e seus clientes. A Floux trabalha com o desenvolvimento de interfaces modulares, responsivas e com os padrões nativos das principais plataformas mobile, com cuidado especial ao uso das palavras para garantir clareza, facilidade de uso e objetividade.

### Métricas
Todo o trabalho da Floux é baseado em dados e também oferece a construção de métricas — sejam KPIs ou OKRs — para que seja possível medir os resultados obtidos e tomar decisões sobre os próximos passos de forma mais consciente e segura.

## Desenvolvimento de código-fonte (opcional)

Além do design, a Floux pode apoiar o time de desenvolvimento na implementação do produto ou desenvolver o produto completo. Esse comprometimento é assumido apenas para aplicações criadas do zero, com o objetivo de colocar o MVP para funcionar e validar as hipóteses de negócio o mais rápido possível.

### Gestão de Recursos
A Floux pode ajudar a estabelecer os recursos de tecnologia necessários para implementar o produto de forma escalável, utilizando servidores e serviços de ponta com alto nível de disponibilidade, de acordo com o tamanho do projeto e disponibilidade de orçamento.

### Código-fonte
Desenvolvimento ágil com boas práticas: código claro, documentado, atendendo os padrões de escrita de cada linguagem, com controle de versão e fluxo adequado de lançamento.

### Manutenção
Manutenção do código-fonte e alta disponibilidade para atuação em caso de emergências, com o mesmo padrão de qualidade da entrega original.
